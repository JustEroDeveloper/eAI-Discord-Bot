# eAI Lite — Intro / Bio

**eAI Lite** is a local-first desktop AI assistant for Windows and macOS.  
It combines Ollama (or any OpenAI-compatible API) with web search, file attachments, and a clean, modern UI.

## What it does
- Chat with local or external AI models
- Search the web and cite sources
- Attach images, `.txt`, and code files
- Censorless mode for uncensored replies
- Thinking/reasoning view for supported models
- Discord bot integration for announcements and changelogs

## Links
- Repository: https://github.com/JustEroDeveloper/eAI
- Latest release: https://github.com/JustEroDeveloper/eAI/releases/latest

## Quick start
1. Install Ollama or configure an external API in **Settings → API**.
2. Run the app (`eai-lite.exe` on Windows or `eAI Lite.app` on macOS).
3. (Optional) Run the Discord bot from `Python Test/bot.py` to auto-post releases and announcements.
